  - Which existing claims should be invalidated (now contradicted or superseded by the new source)

  - Which new claims should be created from the new source

Output strict JSON matching:

{{

    {{"claim_id": <int or null>, "action": "invalidate|reassert|create", "new_subject": "...", "new_predicate": "...", "new_object": "..."}}
  ],

    {{"claim_a_id": <int>, "claim_b_id": <int>, "reason": "..."}}
  ],
  "affected_pages": [<source_id>, ...]
}}

New source (id={new_source_id}):
{new_content}

Neighbor claims:
{neighbor_claims}

Output JSON only. No prose around it.
